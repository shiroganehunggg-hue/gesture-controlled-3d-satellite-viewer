# Gesture-Controlled 3D Satellite Viewer 🛰️✋

An interactive 3D satellite model viewer controlled via real-time hand gestures captured by webcam. Designed as a hands-on exploration of Computer Vision and 3D Interaction for Aerospace/Mechanical Engineering applications.

---

## 🌟 Key Features
- **Real-time Hand Tracking**: Tracks 21 hand landmarks using OpenCV & MediaPipe without requiring special hardware.
- **3D Gesture Interaction**: Smooth translation, rotation, and scaling of complex 3D satellite models (`.stl`).
- **Custom CAD Integration**: Loaded with detailed STL satellite components (command module, escape tower, shroud, couplers, etc.).

---

## 🛠️ Built With
- **Language**: Python 3.11
- **Computer Vision**: OpenCV, MediaPipe
- **3D Rendering**: ModernGL
